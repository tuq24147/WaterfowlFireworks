🦆 Fireworks Free Buffer Zones Near Waterfowl Habitats in Philadelphia

Philadelphia — Waterfowl & Fireworks Buffer Zones

ℹ️ About & Methodology ▼

The main purpose of the map is to visualize proposed 5-10 kilometer buffer zones around key waterfowl habitat areas. These buffer zones represent areas where firework events would be limited or restricted to reduce disturbance to birds from loud noise, bright light, and air pollution. The map shows a visual representation of the spatial relationship between fireworks and waterfowl habitat.

The data for the map would come from both outside sources and manually created points. Waterfowl habitat areas and the species which resided there could be identified using NOAA wetlands data. Firework launch sites were manually added based on common Philadelphia firework event locations where large public firework displays often occur annually. The 5-10 kilometer buffer zones were created around the habitat locations to represent the proposed policy area where fireworks would not be permitted.

I used Leaflet to build the map on Visual Studio and used Amazon Q when I got stuck. I used GeoJSON to store the habitat and firework location data. I learned how to improve map design matters by following visual hierarchy. For example, I made fireworks launch sites stand out clearly from waterfowl habitats to be easy to identify and differentiate. I also made the buffer zones transparent so they did not hide the rest of the map.

I created an interactive map instead of a static map so the user could click on the various habitats to learn their names and what species live there. In addition, they can click on the fireworks sites to see when the events occur. Lastly, the interactive map allows users to zoom in, change buffer size, and understand why certain locations may be more concerning for waterfowl. This map is useful for policymakers because it clearly shows where proposed restrictions would apply and how current fireworks events often occur within close distance of vulnerable waterfowl habitats.
